# Changelog

All notable user-visible changes to the Paperless-ngx TOS application package.

## 3.2.1-1 — 2026-09-27

### Added
- First release. Paperless-ngx (`paperlessngx/paperless-ngx:3.2.1`, Docker Hub official image, unmodified)
  packaged as a TOS 7 Docker application, published on port 8011 and running
  as a non-root user (1000:1000).
- Persistent data is kept under `/Volume1/DockerAppData/paperlessngxdocker/`.
